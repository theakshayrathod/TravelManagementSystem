# TravelManagementSystem
The goal of this project is to build a user-friendly Online Bus Travel Management System that connects passengers and travel operators. Passengers can search buses, view schedules and fares, select pickup/drop points, book tickets, and track their bookings easily.Operators can manage buses, add routes, create schedules (daily, weekly, or custom), and view all bookings. The system stores all travel-related data in one place, making it easier to manage and access information like routes, buses, and schedules efficiently.
